# BESing Official Script Hub

Collection of modular, plug-and-play userscripts designed for the **BESing** framework or any standard userscript manager (Tampermonkey, Violentmonkey, Greasemonkey).

## Script Catalog

| Script | Version | Category | Description |
| :--- | :--- | :--- | :--- |
| **[Reading Assistant](./reading-assistant/reading-assistant.user.js)** | 1.0.0 | Productivity | Calculates word count, estimated reading time, and generates a floating heading outline. |
| **[Night Comfort Dimmer](./dark-dimmer/dark-dimmer.user.js)** | 1.0.0 | Accessibility | Smooth, contrast-preserving dark overlay for late-night reading comfort. |
| **[Markdown Link Copier](./quick-copy/quick-copy.user.js)** | 1.0.0 | Tools | Press `Alt + C` anywhere to copy formatted Markdown link `[Page Title](URL)`. |
| **[Ad Cleaner Lite](./ad-cleaner/ad-cleaner.user.js)** | 1.0.0 | Privacy | Suppresses annoying cookie banners, floating marketing newsletter popups, and sticky overlays. |
| **[Color Change](./color-change/color-change.user.js)** | 1.0.0 | Visual | Demo and testing script for dynamic runtime injection. |

## Dynamic Installation & Greasy Fork Search
When installed inside **BESing**, scripts can be searched and installed with a single click:
1. BESing searches **Greasy Fork** for community versions and updates.
2. If unavailable on Greasy Fork, it downloads the script directly from this GitHub repository.
